Описание компонентов:
bot.py: Этот файл содержит основной код бота, обработчики сообщений и логику взаимодействия с пользователем.
config.py: Здесь находятся все конфиденциальные данные и настройки, такие как токен бота, параметры базы данных и ключи для оплаты.
db/: Папка для работы с базой данных. Включает модели данных и логику запросов.
handlers/: Папка с обработчиками, которые отвечают за различные этапы взаимодействия с пользователем (выбор пола, вида спорта, интенсивности, генерация тренировки и др.).
keyboards/: Папка для клавиатур бота, где создаются кнопки для взаимодействия.
payments/: Модуль для работы с платежами, включая интеграцию с криптовалютными платежными системами.
migrations/: Миграции для базы данных (например, с помощью Alembic для PostgreSQL).
logs/: Логи работы бота, которые помогут в отладке и мониторинге.
requirements.txt: Содержит список зависимостей для проекта, чтобы установить их с помощью pip.


Мне нужен телеграм бот, который будет выдавать список упражнений для тренировок.
Что он должен делать:
- пользователь вводит свои данные: мужчина он или девушка
- вид спорта: фитнес, пауэрлифтинг, тяжёлая атлетика, кроссфит
- уровень нагрузки на сегодняшней тренировки: лёгкий, средний, тяжёлый
- должна быть платная подписка за пользование ботом. плата криптовалютой
Бот должен запоминать предыдущие пол человека, предыдущие тренировки, миксовать упражнения (чтобы тренировка отличалась от предыдущей)


Функционал бота
Регистрация пользователя

Запрашивает пол (М/Ж)
Запрашивает вид спорта (фитнес, пауэрлифтинг, тяжёлая атлетика, кроссфит)
Запрашивает уровень нагрузки (лёгкий, средний, тяжёлый)
Записывает данные в БД
Генерация тренировки

Достаёт из БД последние тренировки пользователя
Подбирает упражнения так, чтобы они отличались от предыдущей тренировки
Отправляет список упражнений пользователю (текст или изображение)
Оплата подписки криптовалютой

Проверяет статус подписки
Генерирует ссылку / адрес кошелька для оплаты
Проверяет поступление платежа (через API биржи или кошелька)
Разблокирует доступ после оплаты
Логирование и анализ

Хранит историю тренировок
Опционально: создаёт отчёты о прогрессе пользователя
