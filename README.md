# fitness_bot
Telegram fitness bot

/training_bot
│
├── bot.py                 # Точка входа, запуск бота
├── config.py              # Конфигурация (токен бота и др.)
├── database.py            # Работа с БД (SQLite) — создание таблиц, CRUD операции
├── handlers.py            # Обработчики команд и сообщений пользователя
├── models.py              # Описание моделей данных (если используешь ORM или структуру)
├── workout_generator.py   # Логика генерации тренировок с учётом предыдущих
├── exercises.db           # Файл базы данных SQLite
└── requirements.txt       # Список зависимостей (aiogram, sqlite3, и др.)



Описание компонентов:

bot.py 
- Запускает Aiogram бота. 
- Подключает обработчики из handlers.py

config.py
- Хранит токен Telegram-бота
- Другие конфигурации, например пути к БД

database.py
- Создаёт таблицы в SQLite:
users (id, telegram_id, пол)

sports (id, название)

exercises (id, название, спорт_id, уровень_нагрузки, описание)

workouts (id, user_id, дата, спорт, нагрузка)

workout_exercises (id, workout_id, exercise_id)

- Функции для добавления/получения пользователей, тренировок и упражнений
- Запоминает историю тренировок

handlers.py
- Команды бота /start, /help
- Сценарий диалога: запрос пола → запрос вида спорта → запрос уровня нагрузки → генерация тренировки → вывод списка
- Хранит состояние пользователя (Aiogram FSM — finite state machine) для диалогов

workout_generator.py
- Получает данные о предыдущих тренировках пользователя из БД
- Формирует новую тренировку, миксуя упражнения так, чтобы не повторять предыдущие
- Учитывает уровень нагрузки (число повторений, веса — можно хранить в описании упражнений или вычислять динамически)


Мне нужен телеграм бот, который будет выдавать список упражнений для тренировок.
Что он должен делать:
- пользователь вводит свои данные: мужчина он или девушка
- вид спорта: фитнес, пауэрлифтинг, тяжёлая атлетика, кроссфит
- уровень нагрузки на сегодняшней тренировки: лёгкий, средний, тяжёлый
- должна быть платная подписка за пользование ботом. плата криптовалютой
- бот должен запоминать предыдущие пол человека, предыдущие тренировки, миксовать упражнения (чтобы тренировка отличалась от предыдущей)


Функционал бота:
- Регистрация пользователя
- Запрашивает пол (М/Ж)
- Запрашивает вид спорта на текущую тренировку (фитнес, пауэрлифтинг, тяжёлая атлетика, кроссфит)
- Запрашивает уровень нагрузки на текущую тренировку (лёгкий, средний, тяжёлый). От вида нагрузки будет зависить отягощение снарядов и количество повторений
- Достаёт из БД последние тренировки пользователя
- Анализ предыдущих тренировок и на основе этого генерирует текущюю тренировку
- Подбирает упражнения так, чтобы они отличались от предыдущей тренировки
- Отправляет список упражнений пользователю (текст или изображение)
- Записывает данные об тренировках в БД
- Оплата подписки криптовалютой
- Проверяет статус подписки
- Генерирует ссылку / адрес кошелька для оплаты
- Проверяет поступление платежа (через API биржи или кошелька)
- Разблокирует доступ к боту после оплаты
- Логирование событий 

Хранит историю тренировок
Опционально: создаёт отчёты о прогрессе пользователя
